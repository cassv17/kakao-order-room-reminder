# 카톡 오더방 미회신 리마인드

지점별 카카오톡 오더방에 본사가 `[레몬하우스 …문의]` 글을 올렸는데 **담당자 회신이 없으면**, 정해진 시간 뒤에 한 번 이렇게 알려 주는 도구입니다.

```
점장님, [단지명 평형] 문의건 통화하셨을까요? 피드백 부탁드립니다. (AI)
```

- 담당자가 2명 이상인 방은 호칭을 빼고 `[단지명 평형] 문의건 …`으로 시작합니다.
- 키보드·마우스·클립보드를 쓰지 않고 **창 메시지로만** 카톡을 조작합니다. 다른 프로그램이나 브라우저로 작업하는 중에도 방해하지 않습니다.
- 기본은 **테스트 모드**입니다. 보내지 않고 "보낼 건이 있다"는 알림만 띄웁니다.

> 이 저장소에는 실제 채팅 내용·직원 이름·전화번호가 없습니다. 방 목록과 직원 이름은 각자 만드는 `설정.json`, `오더방_목록.md`에 두며 `.gitignore`로 올라가지 않게 막아 두었습니다. **저장소는 비공개로 두세요.**

## 필요한 것

- Windows 10/11 + 카카오톡 PC(로그인 상태)
- Python 3.10 이상 (`pythonw.exe`가 PATH에 있어야 예약 실행이 됩니다. 추가 패키지는 없습니다)
- Windows 한국어 OCR: 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션에서 **텍스트 인식**이 설치돼 있어야 합니다.
- 화면 배율 100%를 기준으로 만들었습니다. 다른 배율이면 칩(탭) 판정이 어긋날 수 있습니다.

## 설치 (약 15분)

1. 이 저장소를 받습니다.
2. `설정.예시.json`을 복사해 `설정.json`으로 만들고, 오더방에서 글을 올리는 **본사 직원 이름**을 적습니다. (이 이름이 보낸 사람이면 담당자 회신으로 세지 않습니다. OCR이 자주 잘못 읽는 이름이 있으면 그 변형도 적습니다.)
3. `오더방_목록.예시.md`를 복사해 `오더방_목록.md`로 만들고, 감시할 방을 적습니다.
   - **방 이름은 창 제목과 글자 하나까지 같아야 합니다**(아이콘·띄어쓰기 포함). 방을 열고 제목을 복사하세요.
   - 담당자, 호칭(`점장님`·`대표님`·`(생략)` …), 감시 O/X를 채웁니다.
4. `공휴일.txt`를 올해 공휴일로 고칩니다(한 줄에 `YYYY-MM-DD`).
5. 카톡 메인 창은 **채팅 탭의 `전체`·`안읽음`·`오더방` 탭** 중 하나면 됩니다. 창을 최소화하거나 X로 닫아 트레이에 둬도 됩니다.

## 먼저 시험하기 (보내지 않음)

```bash
python -I 오더방_감시.py
```

- 목록을 읽고 문의를 등록한 뒤 `오더방_보낼목록.json`과 터미널에 결과를 보여 줍니다.
- 처음에는 `오더방_감시.log`와 `오더방_상태.json`을 보며 방 이름 인식과 담당자 판정이 맞는지 확인하세요.
- 보낼 문구가 맞으면 직접 보낼 수도 있습니다: `python -I 오더방_감시.py --send`
- 전송은 **본인만 있는 테스트용 방**으로 먼저 해 보세요: `powershell -ExecutionPolicy Bypass -File 카톡보내기.ps1 -Room "테스트방" -Text "시험" `

## 상시 실행 (작업 스케줄러)

```bash
powershell -ExecutionPolicy Bypass -File 작업등록.ps1
```

월~토 09:00~19:30, 5분마다 돕니다. Windows에 **로그인해 있을 때만** 돌고, 재부팅 후에는 로그인하면 다음 5분 간격부터 다시 돕니다.

며칠 테스트 모드로 로그를 확인한 뒤, 자동 전송으로 바꾸려면 `작업등록.ps1 -Auto`를 실행합니다. 해제는 `작업등록.ps1 -Remove`입니다.

## 동작 방식

1. **목록만 읽기(방을 열지 않음)**: 메인 창을 화면 밖에서 잠깐 키워 채팅 목록 위쪽 두 화면을 캡처·OCR합니다. 미리보기가 `[레몬하우스 …문의]`인 방의 문의를 등록하고 확인 시각을 계산합니다.
   - 영업일(월~토, 공휴일 제외) 17시 전에 올라온 글은 2시간 뒤, 그 밖은 다음 영업일 09:30.
2. **확인 시각이 된 방만 열기**: 화면 밖에서 방을 열어 대화를 OCR로 읽고 담당자가 회신했는지 판단한 뒤 닫습니다. 방을 열면 그 방은 읽음 처리됩니다.
3. **회신이 없으면** 알림(테스트 모드) 또는 전송(자동 모드). 문의 1건당 1회만 보냅니다.

자세한 규칙은 [오더방_리마인드_규칙.md](오더방_리마인드_규칙.md)에 있습니다.

## 안전장치

- 사용자가 카톡 창을 앞에 두고 15초 안에 입력했거나 카톡 검색창에 글자가 있으면 방을 열지 않고 다음 회차로 미룹니다. 60분 넘게 밀리면 알림을 한 번 띄웁니다.
- 방 창 제목이 정확히 같을 때만 보냅니다. 입력칸에 쓰던 글이 있으면 덮어쓰지 않고 멈춥니다.
- 보내기 직전에 회신이 왔는지 다시 확인합니다.
- 감시 시작 전에 이미 기한이 지난 문의는 보내지 않습니다(`old`).
- 동시에 하나만 실행합니다(잠금 파일). 중간에 끊겨 창이 화면 밖에 남으면 다음 실행이 되돌립니다.
- 정말 실패(카톡 종료·창 없음 등)가 3번 연속이면 알림을 한 번 띄웁니다. 미룸은 실패로 세지 않습니다. 알림은 **확인을 누를 때까지** 남습니다.
- 메인 창의 칩(탭)은 클릭하지 않습니다. 메시지로 클릭하면 칩 순서가 바뀌는 문제가 있습니다.

## 한계

- 메인 창이 `전체`·`안읽음`·`오더방` 탭이 아니거나(예: `중요`) 검색창에 글자가 있으면 읽지 못하고 미룹니다. `안읽음` 탭은 이미 읽은 방이 목록에 안 보입니다.
- 문의 바로 뒤에 다른 글이 연달아 올라와 목록 미리보기에 문의가 한 번도 안 보이면 놓칩니다. 오래 꺼 둔 날에는 재개 후 오더방을 한 번 훑어보세요.
- OCR 기반이라 이름·전화번호를 한두 글자 틀리게 읽을 수 있습니다(전화번호는 오차를 허용해 비교합니다).
- 카카오톡 업데이트로 창 구조가 바뀌면 동작하지 않을 수 있습니다.
